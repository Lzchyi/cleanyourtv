# CleanYourTV personal fork

- The native Java launcher is in `launcher/`; application ID is `com.gathin.tvhome`, minSdk 26, compile/target SDK 34. Keep AndroidX RecyclerView and DynamicAnimation; avoid new runtime dependencies, network permission and new background services.
- This fork's premium redesign uses `HomeGeometry` for independent four-slot dock/grid rows, `LibraryNavigation` for sorted vertical Library navigation, shared `premium_design.xml` resources, and one bounded worker-generated wallpaper blur cache. Never allocate or blur full wallpaper buffers per animation frame.
- `apps_key_library` is an opt-in resource mode of the existing HomeKeyService: handle only semantic ALL_APPS or the observed Sony VRC 001 Apps scan with matching vendor/product. Pass all unrelated keys unchanged; do not repurpose Home/recents globally or subscribe to screen-content events. Verify physical remote behavior separately from injected events.
- Keep existing `launcher_settings`, wallpaper and Home-order keys compatible. The removed calendar feature has no runtime parser; leave existing external theme files untouched so upgrades do not invalidate on-TV choices. Keep the separate F1 TV app untouched.
- Build and host checks: from `launcher/`, JDK 17 and Android SDK 34, run `./gradlew --no-daemon testReleaseUnitTest lintRelease assembleRelease`. Repository tool/docs checks: `python3 -m unittest discover -s tests -v`. Never launch or test a simulator/emulator. Actual TV, physical remote, playback and performance checks are separate and must be reported accurately.
- A private release resource overlay can preserve an existing TV's compiled defaults with `-PlauncherResourceOverlay=/absolute/res/directory`. Do not commit local overlays, SDK paths, signing/ADB keys, caches, private device dumps or generated build output. The installed TV upgrade must use its existing signing key; a fresh CI debug key is a different identity.
- Keep changes on this user's fork and branch. Do not modify the original upstream repository. Preserve generic vendor input/remote compatibility and leave unrelated debloat tools alone.
